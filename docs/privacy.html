Privacy Policy

SelectMind AI · Last updated: November 4, 2026

SelectMind AI is a Chrome / Firefox browser extension and a desktop app (Windows / Linux) that helps you analyze, explain, translate, and chat about selected text, OCR captures, and (on desktop) live game UI using AI providers and translation engines you configure.

Summary

  • We do not operate servers that collect your personal data.
  • Your settings, conversations, and API keys stay on your device.
  • When you run an AI action, requests go directly from your device to the AI provider you chose (OpenAI, Anthropic, Google Gemini, Ollama, etc.).
  • Desktop live translate may send OCR text to free/proxy engines you select, or keep it offline with Argos NMT.
  • We do not use analytics, advertising, or tracking.

Data stored locally

Browser extension

  • Settings — theme, language preferences, toolbar layout, and similar options.
  • API keys — encrypted using Web Crypto (AES-GCM) and saved in browser local storage. Keys are never sent to us.
  • Conversations — chat history and messages in IndexedDB on your device.
  • Custom actions & pipelines — prompts and workflows you create or import.

Desktop app

  • Settings — stored locally on the device.
  • API keys — OS credential store (Windows Credential Manager / Linux Secret Service).
  • Conversations — SQLite database on your device.
  • Offline models — optional Argos NMT (and similar) files you download.

You can delete conversations in the app UI or remove all data by uninstalling the extension / app.

Data sent to third parties

When you trigger an AI action (Explain, Translate, Chat, OCR, etc.), the client may include in the request to your configured provider:

  • Text you selected
  • Page title and URL (extension) or window context (desktop)
  • Screenshot images and OCR text when you use screen capture / OCR
  • Your prompt and conversation history for that thread

Live game translate (desktop): text from the screen region you chose may be sent to Google, Bing, Lingva, LibreTranslate, or another engine you select. Offline Argos NMT does not send that text off-device. AI-provider mode uses your configured provider.

Custom OpenAI-compatible base URLs receive the same kind of payload as other providers you configure. Third-party privacy policies apply to those services.

Extension API-key encryption

Keys are encrypted at rest in browser storage with a key derived from the extension installation. This is not a user passphrase. Prefer the desktop OS keyring when you need stronger OS-level protection.

Permissions (browser extension)

  • storage — save settings and encrypted API keys
  • activeTab — read selected text and page context on the current tab
  • sidePanel — show the workspace side panel
  • contextMenus — right-click menu on selected text (SelectMind AI → actions)
  • alarms — optional automatic cleanup of old conversations
  • host access (<all_urls>) — inject the toolbar and chat UI on pages you visit

Donations

The product may show an optional link to support development via Privat24. Donations are handled entirely outside SelectMind AI by PrivatBank; we do not receive or store payment data through the extension or desktop app.

Children

SelectMind AI is not directed at children under 13. We do not knowingly collect data from anyone.

Changes

We may update this policy. The “Last updated” date at the top will change when we do.
