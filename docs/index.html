SelectMind AI

Chrome / Firefox extension · Desktop (Windows & Linux) · Privacy-first AI

Select text and instantly explain, translate, summarize, or chat — using OpenAI, Anthropic, Gemini, Ollama, or any OpenAI-compatible API you configure. On desktop: system-wide toolbar, OCR, and live game translate. API keys and conversations stay on your device.

Features

  • Floating toolbar on text selection (extension and desktop)
  • Side panel / workspace with conversation history
  • Screen OCR — capture a region and run AI actions
  • Live game translate with Continuous mode (desktop v0.2)
  • 30+ built-in actions, custom prompts, and pipelines
  • Command palette (Ctrl+Shift+P)

Versions

  • Extension v0.1.1 — Chrome / Firefox / Zen
  • Desktop v0.2.x — Windows & Linux (Tauri 2)

Getting started

  1. Install the Chrome extension, Firefox build, or desktop app from the repository README
  2. Open Settings and add your AI provider + API key
  3. Select text, use OCR, or (on desktop) start live game translate
