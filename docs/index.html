SelectMind AI

Chrome extension · Privacy-first AI on any webpage

Select text on any page and instantly explain, translate, summarize, or chat — using OpenAI, Anthropic, Gemini, Ollama, or any OpenAI-compatible API you configure. API keys and conversations stay on your device.

Features

  • Floating toolbar on text selection
  • Side panel workspace and conversation history
  • Screen OCR — capture a region and get an AI explanation
  • 30+ built-in actions, custom prompts, and pipelines
  • Command palette (Ctrl+Shift+P)

Links

GitHub repository Support & issues Privacy policy

Getting started

  1. Install SelectMind AI from the Chrome Web Store
  2. Open extension Settings and add your AI provider + API key
  3. Select text on any webpage or use OCR from the side panel
